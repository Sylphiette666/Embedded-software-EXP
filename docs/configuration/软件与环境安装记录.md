## 日常使用

桌面“STM32实验工具”快捷方式指向 `D:\F411_LabTools\启动入口`。

1. 打开“01 Keil 实验工程”，在 Target 下拉框选择对应实验，F7 编译，再按实验流程下载。
2. 打开“02 串口终端 UTF8”，会自动寻找唯一的 ST-Link 虚拟串口并使用实验配置。换 USB 口不必手动固定 COM3。
3. 串口终端打开后，直接按大写 Y/N 可用于实验六；实验八由 PA0 实体按键触发中文输出。终端本地回显关闭，所以未收到固件回复时不一定能看到刚输入的字符。
4. 同一 COM 口只能由一个程序使用。执行 UART ISP 或其他串口工具之前，先关闭 Tera Term。
5. “03 环境检查（不烧录）”会重新编译全部 Target 并执行软件检查；不会连接并改写开发板。日常只需要 Keil 和串口终端，不必每次完整检查。

手动指定串口：

```powershell
powershell -ExecutionPolicy Bypass -File D:\F411_LabTools\open_serial.ps1 -Port COM3
```

运行检查：

```powershell
powershell -ExecutionPolicy Bypass -File D:\F411_LabTools\check_environment.ps1
```

仅列出调试器与目标支持：

```powershell
D:\F411_PythonEnv\Scripts\python.exe -X utf8 -m pyocd list --config D:\F411_LabTools\pyocd.yaml
```

本工程采用标准外设库，不需要 STM32CubeMX、STM32CubeIDE、Arduino IDE 或 Proteus 才能编译运行。板载 ST-Link 所需驱动已正常，不需要为它安装 CH340/CP210x 驱动；以后如果使用独立 USB 转串口模块，再按模块型号准备驱动。
